## Dependências

Para correr o projeto, é necessário ter o [cryptography](https://cryptography.io/en/latest/) e o [prompt-toolkit](https://python-prompt-toolkit.readthedocs.io/en/3.0.52/) instalados. Para isso, execute o seguinte comando:

```bash
pip install cryptography prompt-toolkit
```

## Arranque

Na diretoria do projeto, execute o seguinte comando para iniciar o servidor:

```bash
python3 server.py
```

Em seguida, para iniciar um cliente, execute o seguinte comando:

```bash
python3 client.py
```
